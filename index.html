39+## ⚙️ Funcionamiento del Pipeline
40+
41+1. **Checkout & Git Config**: El flujo de GitHub Actions clona el repositorio con profundidad completa (`fetch-depth: 0`) y configura la identidad del agente automatizado.
42+2. **Análisis y Generación**: El script de Python `analizador.py` recopila el log de git, analiza el diff de los archivos modificados y genera el archivo `index.html` optimizado para la raíz del sitio.
43+3. **Modificación Remota (Amend)**: Si el commit actual no cumple con el formato estándar, el script ejecuta localmente `git commit --amend` y actualiza la rama remota mediante `git push --force`.
44+4. **Despliegue Continuo**: El artefacto generado se empaqueta y se publica instantáneamente en **GitHub Pages**.
